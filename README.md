# S0A2E website upload

Upload all five files in this folder to the root of the GitHub repository:

- `.nojekyll`
- `CNAME`
- `index.html`
- `loop.mp4`
- `README.md`

Then open the repository's **Settings → Pages** and publish from the `main`
branch and `/ (root)` folder.

The video begins muted because mobile browsers block automatic audio. Tapping
**TAP FOR SOUND** restarts the loop from the beginning with audio.
